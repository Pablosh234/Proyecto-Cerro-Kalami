# Página web — Cerro Kalami

## Archivos
- `index.html` — página completa.
- `styles.css` — diseño responsive.
- `script.js` — menú móvil y reproductor.
- `assets/video-final.mp4` — coloca aquí tu video final.
- `assets/video-poster.jpg` — opcional: imagen de portada del video.

## Cómo usarla
1. Copia tu video final dentro de `assets/` y llámalo `video-final.mp4`.
2. Opcionalmente coloca una imagen de portada llamada `video-poster.jpg`.
3. Abre `index.html` en el navegador para comprobarla.

## Publicarla gratis
### Netlify
Puedes arrastrar la carpeta completa a Netlify Drop. La documentación oficial indica que el proyecto puede publicarse mediante drag & drop y recibirá una URL `netlify.app`.

### GitHub Pages
También puedes subir la carpeta a un repositorio público y activar GitHub Pages. GitHub Pages permite publicar archivos estáticos de un repositorio.

## Importante
Las tarjetas de storyboard actualmente usan numeración estilizada como marcador. Si quieres que cada tarjeta muestre las imágenes reales de tus 12 escenas, coloca las imágenes en `assets/` y reemplaza los bloques `.scene-img` por etiquetas `<img>`.
